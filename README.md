# Bajinka: Nottingham City

An original Nottingham-inspired 3D game project, planned for Godot 4 with GDScript.

## First playable milestone

- One small street with solid ground and building collisions.
- One third-person character with walking, running and a follow camera.
- One vehicle with entry, driving, braking, reversing and safe exit.

## Project status

Repository initialized. The playable Godot project has not been implemented yet.

## Development approach

Build and verify small playable milestones before adding combat, police, additional vehicles or multiplayer. Use original or appropriately licensed assets and record attribution.

GitHub stores the source code. Godot is required to edit and run the game locally.
